# Hildur Yeoman — redesign prototype

An unofficial design prototype for [hilduryeoman.com](https://hilduryeoman.com), built as a
concept by [SNDR Studio](https://sndr-studio.pages.dev). This is **not** the real Hildur Yeoman
website and is not affiliated with or endorsed by Hildur Yeoman.

Product imagery and the logo belong to Hildur Yeoman and are referenced from their own CDN for
demonstration purposes only. Marked `noindex`.

Static site: vanilla HTML/CSS/JS, GSAP + Lenis.
